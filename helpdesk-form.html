Filter FAQs

Most mobile Wi-Fi complaints are related to enterprise network settings that have not been entered correctly. Add the eduroam network manually using the following settings:

  1. Security: WPA/WPA2-Enterprise
  2. EAP method: PEAP
  3. Phase 2 authentication: MSCHAPV2
  4. CA certificate: Use system certificates
  5. Online certificate status: Do not verify
  6. Domain: muet.edu.pk
  7. Identity: your.name@muet.edu.pk
  8. Anonymous identity: Leave blank
  9. Password: Your MUET account password
Use your official MUET email account. If the connection still fails, forget the saved eduroam network, restart Wi-Fi and enter the settings again.

If your computer is slow, first check the available RAM and review the applications running in Windows Task Manager.

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Check CPU, Memory and Disk usage.
  3. Close unnecessary applications running in the background.
  4. Restart the computer and check whether performance improves.
  5. If memory usage remains high, the system may require additional RAM or hardware inspection.
Do not terminate unknown Windows system processes. If the computer remains slow, submit a complaint for technical inspection.

If Windows is corrupted, repeatedly showing errors, or cannot start properly, the system may require Windows reinstallation or hardware checking.

  • Back up important files if the system is still accessible.
  • Do not format the computer before saving important data.
  • Take the PC to a reliable PC repair shop for Windows installation and hardware inspection.
  • If the computer is an official MUET system, mention the issue clearly in the complaint form.
Windows installation and hardware repair may require physical inspection. ICPC can guide you regarding the next step.

If your telephone extension has no dial tone, perform the following checks:

  1. Borrow a working telephone from a nearby office.
  2. Connect the working telephone to your extension line.
  3. Check whether the dial tone is available.
  4. Check the telephone cable and ensure that both plugs are connected properly.
  5. Check the cable connection in the telephone IO board.
  6. If there is still no tone, submit a complaint with the extension number and location.
Please provide the extension number and office location so the ICPC team can identify the line.

For Windows or Microsoft Office activation assistance, download or install the official AnyDesk remote-support application and provide the connection ID to the concerned ICPC person.

  1. Download and install AnyDesk from its official website.
  2. Open AnyDesk on the computer requiring assistance.
  3. Send the AnyDesk connection ID to the authorized ICPC person.
  4. Keep the computer switched on and connected to the internet.
  5. Accept the remote session only after confirming the identity of the ICPC support person.
Never share your personal password or allow unknown persons to access your computer. Remote activation should be performed only by authorized ICPC personnel.

If your PC is connected to the MUET network but internet access is not working, check the following:

  1. Check that the network cable is properly connected.
  2. Open the network settings and confirm that the network adapter is enabled.
  3. Check whether the computer shows a connection to the MUET network or muet.edu.pk.
  4. Restart the network adapter or restart the computer.
  5. If the MUET network is connected but internet access is unavailable, download or copy the VPN installation software from:
    ftp://172.16.100.69
  6. Install the VPN software and connect using your authorized MUET credentials.
Use only your authorized MUET credentials. If VPN access is still unsuccessful, submit the complaint with your department, PC name if available, and the exact error message.

Please provide your name, extension or contact number, department/location, complaint type and a clear description of the problem.

  • Mention the exact location of the equipment.
  • Include the extension number or PC name where applicable.
  • Describe any error message displayed.
  • Explain the troubleshooting steps already attempted.
